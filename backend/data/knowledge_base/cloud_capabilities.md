> **SYNTHETIC / DEMO DATA** for the fictitious company NorthPeak Digital Partners.

# Cloud Capabilities

## Supported Platforms
NorthPeak is a delivery partner (non-premier tier, self-declared for this demo) on AWS and
Microsoft Azure, with a smaller number of engagements on Google Cloud Platform. Core services
used: AWS ECS/EKS, Lambda, RDS, S3; Azure AKS, Functions, Azure SQL; GCP GKE and BigQuery.

## Landing Zone & Governance
NorthPeak deploys multi-account/subscription landing zones with centralized logging, budget
alerting, and guardrail policies (AWS Control Tower / Azure Policy) as a standard part of cloud
migration engagements.

## Migration
NorthPeak has executed lift-and-shift and re-platforming migrations for application estates in
the 20-150 server range. NorthPeak has not documented a migration engagement above 500 servers in
a single program; larger estates would need to be scoped as a phased program with an assumption
of extended timeline.

## High Availability & DR
Standard architecture patterns target multi-AZ deployment with defined RPO/RTO objectives agreed
per engagement. NorthPeak does not maintain a standing multi-region active-active reference
architecture; active-active designs are handled as bespoke architecture work.

## Cost Management
NorthPeak provides cloud cost optimization reviews (rightsizing, reserved instance/savings plan
analysis) as a recurring managed service offering.
