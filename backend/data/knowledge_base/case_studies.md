# Case Studies

## Case Study A — AI-Enabled Workflow Automation (Retail)
For a national retail chain (~300 stores), NorthPeak built a document-processing pipeline using
RAG and structured extraction to automate vendor invoice reconciliation, reducing manual review
time by an estimated 60% in the pilot period. The system used a human-in-the-loop review step
for any extraction below a confidence threshold. Delivered over a 4-month engagement.

## Case Study B — Cloud Migration (Logistics)
For a regional logistics provider, NorthPeak migrated a 45-server on-premises application estate
to AWS over a 6-month program, implementing a multi-AZ landing zone and a phased cutover plan.
Post-migration, the client reported a reduction in unplanned downtime incidents.

## Case Study C — Customer Data Platform (Financial Services)
For a mid-sized financial services firm, NorthPeak implemented a customer data platform on
Snowflake with role-based access control and lineage tracking to support internal audit
requirements. The engagement included a GDPR data-subject-request workflow for the client's EU
customer base.

## Case Study D — Conversational Support Assistant (Retail)
For an e-commerce client, NorthPeak built a customer-support assistant grounded in the client's
product and policy documentation, with citation of source documents in every response and an
escalation path to human agents when confidence was low.

## Note on Scope
These four case studies are the only project narratives in this demo knowledge base. RFP
requirements asking for case studies in domains not covered above (e.g., healthcare,
