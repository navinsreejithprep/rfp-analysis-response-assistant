# Certifications & Attestations

- **Cloud partner status**: NorthPeak self-identifies as an AWS and Microsoft Azure delivery
  partner at a standard (non-premier) partner tier for this demo scenario.
- **Individual certifications held across staff**: AWS Certified Solutions Architect (multiple
  staff), Microsoft Certified: Azure Solutions Architect Expert (multiple staff), Certified
  Kubernetes Administrator (CKA) (a small number of staff).
- **Security certifications held across staff**: a small number of staff hold CISSP or
  equivalent security certifications.
- **Corporate-level attestations NorthPeak does NOT hold** (explicitly, for this demo): no
  FedRAMP authorization; no published, independently audited SOC 2 Type II or ISO 27001
  certificate for NorthPeak's own corporate environment; no CMMI appraisal on record.

## Guidance for Evaluators
Where an RFP requirement asks for a specific corporate certification not listed as "held" above,
the correct classification is that the evidence does not establish the certification exists —
it should not be assumed present by extrapolation from individual staff certifications or from
client-facing compliance support work described elsewhere in this knowledge base.
