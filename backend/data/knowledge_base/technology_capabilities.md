> **SYNTHETIC / DEMO DATA** for the fictitious company NorthPeak Digital Partners.

# Technology Capabilities

## Application Development
NorthPeak builds and modernizes web and mobile applications using React, Next.js, TypeScript,
Node.js, Python (FastAPI/Django), and Java (Spring Boot). Standard practice includes CI/CD
pipelines (GitHub Actions, GitLab CI), infrastructure-as-code (Terraform), and automated testing
as a condition of release.

## Systems Integration
NorthPeak has delivered integrations against REST and GraphQL APIs, SOAP-based legacy systems,
and common enterprise platforms including Salesforce, SAP (via BAPI/RFC connectors), and
Workday. Integration work typically uses an API-gateway pattern with centralized authentication
and rate limiting.

## Data Architecture
NorthPeak designs data platforms using both batch (dbt, Airflow) and streaming (Kafka, Kinesis)
patterns, targeting warehouses such as Snowflake and BigQuery. NorthPeak does not currently
maintain a dedicated mainframe-modernization practice; engagements requiring COBOL/mainframe
migration would need to be scoped with a specialist partner.

## Accessibility & Standards
NorthPeak's front-end delivery standard requires WCAG 2.1 AA conformance testing before release
for public-sector and regulated-industry clients. Internal tooling applies the same standard on
a best-effort basis but is not independently audited.

## Explicit Non-Capability
NorthPeak does not build or maintain proprietary hardware, IoT firmware, or embedded systems.
Requirements calling for hardware manufacturing or firmware development are outside NorthPeak's
service offering.
